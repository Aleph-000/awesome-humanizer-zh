# awesome-humanizer-zh

`awesome-humanizer-zh` 收集了一组面向中文写作的语言风格提示词。它关注句子是否符合现代汉语习惯，段落能否沿着清楚的思路展开，以及评价有没有具体内容支撑。

许多文字在语法上没有错误，读起来却离自然中文很远。例如，一篇文章可能频繁使用“不是……而是……”制造转折，用“高级感”“氛围感”概括作品，或者写下“歌词很厚实”“处理很漂亮”后便结束评价。读者看见了作者的态度，却不知道判断来自哪些歌词、画面、声音或人物行动。项目中的规则把这些问题逐项标出，并给出明确的调整方向。

## 规则从哪里来

项目内容来自实际写作中的人工观察。每当一段文字出现生硬搭配、空泛评价、机械过渡或不自然的段落结构，就把问题记录下来，写成提示词，再根据后续生成结果继续修正。现有内容均由人工逐条撰写，没有从其他提示词文件中摘录或改写。

## 针对中文表达制定的规则

英语提示词经过直接翻译，往往难以处理中文写作中特有的问题。本项目根据现代汉语的用词和句法习惯，加入了更具体的要求。

### 避免生硬的单字词语

模型为了让句子显得简洁有力，容易把原本自然的词组压缩成“取、停、推、挂、记、接”等单字动词，也会生硬地插入“还、很、也”等单字副词。这样的句子看似短促，实际缺少中文惯用的搭配关系。例如，“孤零零地挂在歌词上”和“这个名字值得记一下”都带有刻意加工的痕迹。规则要求优先使用完整、常见的现代汉语搭配，让词语在句子中的关系清楚自然。

### 完整展开评价

“歌词很厚”“处理很漂亮”“这句话很好”只表达了态度，没有交代作品的具体表现。规则要求评价继续向下展开：引用或概括相关内容，指出词语、画面、声音或结构如何发挥作用，再说明判断成立的理由。完整的分析过程会把观点和依据连接起来，孤立的形容词也就失去了存在的必要。

### 减少抽象词和“××感”

“空间感”“故事感”“宿命感”等词能够快速概括印象，连续使用时却容易遮住作品本身。规则要求把这些印象还原成可以观察的细节，例如声音远近如何变化、人物做了什么、画面怎样安排，以及歌词用了哪些具体意象。文学性的表达仍然可以保留，但需要建立在真实内容上。

### 调整机械的转折句式

生成文字常用“不是……而是……”“没有……反而……”制造二元对立，即使上下文并不需要如此强烈的转折。项目建议在能够直接说明观点时写出正面内容，使句子围绕真正的信息展开，减少为了语气和节奏添加的反面铺垫。

### 按照中文读者的认识顺序组织内容

文章第一次提到陌生人物、歌词、采访或历史事件时，先交代人物身份、发生场景和必要背景，再引用与分析。段落从具体对象进入细节，最后补充能够帮助理解的背景资料。读者会先认识正在讨论的对象，再沿着细节进入分析，文章也能始终围绕作品本身展开。

### 让故事服务于当前主题

人物经历、制作故事和历史资料只有在帮助读者理解作品时才展开。规则鼓励通过选择、行动、采访和实际经历塑造人物，同时控制背景篇幅，不急着总结性格或提炼人生哲理。文章可以自然地讲故事，也始终保留清楚的中心。

## 一个简单例子

修改前：

> 这段歌词很有故事感，编曲也很高级。它不是在写普通的离别，而是在写一种强烈的宿命感。

修改后：

> 歌词先写主人公收起桌上的两套餐具，接着让门外的脚步声逐渐消失。编曲在这里撤去鼓点，只留下贴近人声的钢琴。生活里的具体动作和突然空下来的声音共同表现离别，比直接说“舍不得”更能让人理解人物当时的处境。

修改后的段落交代了歌词、声音和人物动作，评价也有了可以核对的依据。规则关注的正是这种具体变化。

## 与 Humanizer-zh 的区别

[Humanizer-zh](https://github.com/op7418/Humanizer-zh) 参考英文原版并进行了中文翻译。

`awesome-humanizer-zh` 独立编写，创作过程中未参考 `Humanizer-zh` 或其他已有文件。全部规则来自中文写作中的手工标注、提示词编写和反复纠正，内容直接围绕中文语境下的措辞、句式、段落组织与赏析写作展开。

## 使用方式

打开 [SKILL.md](./SKILL.md)，根据需要复制完整内容或其中相关章节，将其加入模型的提示词或自定义指令即可。规则既可以用于生成新内容，也可以用于检查和修改已有文章。
