# awesome-humanizer-zh

`awesome-humanizer-zh` 是一份面向中文写作的语言风格提示词，用于标注并纠正常见的生硬表达，使文字更加自然、完整，也更符合现代汉语的表达习惯。

## 与 Humanizer-zh 的区别

[Humanizer-zh](https://github.com/op7418/Humanizer-zh) 参考英文原版并进行了中文翻译。

本项目没有参考 Humanizer-zh 或其他已有文件，全部规则均来自实际写作过程中的人工观察、手写标注和反复纠正。内容重点放在中文语境下的句式、措辞、段落组织与赏析写作习惯，而非对英文提示词的翻译或改写。

具体规则见 [SKILL.md](./SKILL.md)。
