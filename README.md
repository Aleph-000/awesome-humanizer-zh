# awesome-humanizer-zh

`awesome-humanizer-zh` 整理了一份中文写作与改稿规则，完整内容见 [SKILL.md](./SKILL.md)。可以把它交给模型，与写作任务或待修改的文章一起使用，检查词语搭配、句式、段落组织和引用方式。

规则中记录了不少具体问题：用“很有故事感”概括一段描写，用“把观点推得更具体”表达本来可以直接说明的意思，介绍人物时突然引用半句话，或者在每段末尾补上一句抽象评价。文件保留了这些反例及相应的修改要求，便于对照原句判断问题。

## 怎么用

打开 [SKILL.md](./SKILL.md)，将全文复制到对话中，或作为文件提供给模型，再附上具体任务。也可以挑选与当前任务有关的部分，加入提示词或自定义指令。

下面两段提示词可以直接复制使用。使用前，请先提供 `SKILL.md` 的内容。

### 修改已有文章

```text
请先完整阅读我提供的 SKILL.md，再修改下面的文章。

保留原文的事实、观点、专名、数据和必要的技术细节，按照规则检查词语搭配、句式、段落组织和引用方式。删去重复的评价与空泛总结，让已有的事实、例子和分析得到清楚、完整的表达。

需要背景才能理解的内容，请根据已有材料补充或调整介绍顺序。材料不足时单独指出，不能为了让文章更具体而编造经历、引语或细节。

输出修改后的全文；确有需要核实的信息，放在文末简要说明。

待修改的文章：
[粘贴原文]
```

### 撰写新文章

```text
请先完整阅读我提供的 SKILL.md，再根据以下要求写作。

主题：
读者：
用途与篇幅：
必须包含的内容：
可使用的材料：

按照读者理解内容所需的顺序展开。人物、事件和引用首次出现时，交代必要背景；评价结合具体内容说明理由。背景故事的篇幅服从文章主题。

事实以提供的材料或核实后的来源为依据，区分事实与分析。不要虚构个人经历、采访、引语或数据。
```

## 主要检查哪些地方

[SKILL.md](./SKILL.md) 中的要求涉及措辞与内容组织，以下按改稿时需要处理的问题归纳。

**词语搭配和句式。** 检查“取得很漂亮”“推得更具体”“值得记一下”等表达在语境中是否准确、自然，改成意思明确的现代汉语。能够直接说明的内容，减少不必要的否定、转折和铺垫。

**评价和段落。** “处理很漂亮”“这句话很重要”需要具体理由。已有细节足以说明的地方，可以删去重复评价；确实需要分析的地方，应把相关内容和判断依据写完整。段落根据内容安排，减少为强调意义而单独写出的抽象总结。

**人物介绍和引用。** 陌生人物、歌词、采访和情节第一次出现时，交代身份、场景与上下文。引用保留足以理解原意的内容，随后再分析，避免让读者凭一个陌生名字或半句话猜测背景。

**作品赏析。** 从歌词、画面、声音、人物动作和制作细节展开。介绍音乐制作时，说明实际听到的变化，控制陌生术语的数量。创作者经历、制作故事和历史背景可以穿插，篇幅围绕当前作品安排。

## 几个改写示例

以下例句为说明规则而编写，均不涉及真实人物或作品。改写只调整表达和组织方式，保留原句已有的信息。

### 把生硬的搭配换成直接的说明

原句：

> 这段采访把他的创作想法推得更具体。他说，写作时会先确定人物想做什么，再考虑故事怎样发展。

改写：

> 他在采访中谈到自己的写作方法：先确定人物想做什么，再考虑故事怎样发展。

后一句已经说明了具体的创作方法，可以把采访内容直接写出来，删去“推得更具体”这层重复的说明。

### 删去细节之后多余的评价

原句：

> 照片里，搬家的人坐在尚未封箱的行李旁，手里拿着一张旧照片。
>
> 这一幕很有故事感，也很值得回味。

改写：

> 照片里，搬家的人坐在尚未封箱的行李旁，手里拿着一张旧照片。

第二段只表达了笼统的感受。删去以后，人物的动作和周围的物品仍然完整保留；需要进一步分析时，可以从这些具体内容展开。

### 在引用前交代人物和场景

原句：

> “我想让开头像一个人在房间里说话。”这个想法很好。这句话来自负责这首歌编曲的制作人，是他介绍录音过程时说的。

改写：

> 负责这首歌编曲的制作人在介绍录音过程时说：“我想让开头像一个人在房间里说话。”

人物身份和谈话场景提前后，读者可以直接理解这句话的出处。“这个想法很好”缺少判断依据，改写时一并删去。

## 使用时怎样取舍

规则记录了作者的写作偏好，使用时需要结合文体与具体句子判断。“还”“很”“也”等词在自然的表达中可以保留，必要的转折、短段落和修辞同样有各自的用途。检查的重点是当前表达是否准确、是否有助于理解，避免逐字替换造成新的生硬搭配。

改稿时应以原文的意思和事实为准。原文只有笼统评价、缺少具体材料时，可以指出需要补充什么，或删去缺乏依据的判断。人物经历、采访内容、数据和作品细节都需要材料支持，语言上的润色应当保留这些事实边界。
